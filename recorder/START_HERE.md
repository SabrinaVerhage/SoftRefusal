## Open, talk, stop

1. Double-click **Open Gemma Recording Room.cmd** in this folder. A local browser page opens. It does not start automatically with Windows.
2. Start a new conversation or select an existing one. Write a message and press Enter. Gemma loads on your first message; this computer runs it on its CPU, so replies can be slow.
3. Choose **Reply length** before sending. The default is 512 tokens; you can choose 256, 1,024 or 2,048. A token is a piece of text, not necessarily a whole word. This is a ceiling, not a requested length. Gemma may finish earlier.
4. Click **Follow the computation** to see actual token pieces, small numerical matrix previews, the layer pass, and the leading candidates for the next token. Leave it open while Gemma replies; use the slider to revisit its token choices.
5. Wait for **Recording saved**. Your conversation and measurements are already on disk. You do not need to download anything to save them.
6. Use **Stop app & release memory** when finished, or double-click **Stop Recording Room.cmd**. Closing a browser tab alone leaves the local server and loaded model running. If a reply is active, stopping the app cancels it safely and then closes. A calculation already in progress must finish first; the stop launcher now displays progress.

**Stop reply** cancels an unfinished answer. Earlier complete turns stay safe. The unfinished attempt remains in a separate activity log and is not silently added to the conversation dataset.

## Why did answers get cut off?

The initial app capped replies at 256 tokens to keep laptop runs manageable. That setting can cut a sentence off regardless of its subject. The app labels such replies as unfinished. The new selector lets you increase the cap. A refusal generated by Gemma is a different event; there is no additional sexual-content filter in this app.

There is also a separate 2,048-token limit for the **incoming conversation**, including earlier replies and formatting. When that is exceeded, the app asks you to start a new conversation instead of secretly removing history. A very long reply can bring the next turn over that limit. Neither limit is Gemma's full architectural capacity; these are initial recording settings for this computer.
